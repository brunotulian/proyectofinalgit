# Proyecto Final - Git y GitHub

## Descripción
Repositorio inicial del proyecto web.

## Tecnologías
- HTML5
- Git & GitHub

## Flujo de Trabajo y Colaboración
Este proyecto utiliza un flujo de trabajo basado en **Feature Branching**:
- Desarrollo de nuevas funcionalidades en ramas independientes.
- Registro de commits descriptivos.
- Integración a la rama main mediante Pull Requests en GitHub.
